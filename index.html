DevSecOps · B.Tech final-year project · PRD v2.0, planned MVP

SecureFlow

Scan every pull request. Get a prioritized security report before code is merged.

SecureFlow connects to a GitHub repository, runs Trivy (dependency vulnerabilities) and Gitleaks (exposed secrets) when code changes, and shows developers what to fix first. It orchestrates established scanners rather than inventing a new detection engine.

  1. WebhookGitHub PR event
  2. VerifyHMAC and dedupe
  3. QueueCelery and Redis
  4. ScanTrivy and Gitleaks
  5. NormalizeRedact and dedupe
  6. ReportDashboard and check
Simulated scan of a pull request
Press “Run simulated scan” to follow a pull request through the pipeline.

0 Critical 0 High 0 Medium Merge blocked

    • Verified webhooks. HMAC signature checked on the raw request body, with delivery-ID idempotency.
    • Untrusted by default. Non-root worker, no repository code executed, temporary files always cleaned up.
    • Secrets stay hidden. Redacted from logs, storage and UI. Every query is scoped to a workspace.
    • FastAPI
    • Celery
    • Redis
    • MongoDB
    • Trivy
    • Gitleaks
    • React
    • TypeScript
    • Docker

    The demo is a simulation with seeded data and a dummy credential. SecureFlow is at the PRD stage, with implementation planned over six months.
